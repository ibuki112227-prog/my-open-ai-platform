# My Open AI Platform

An open-source AI chat platform I'm building as a junior high school student in Japan.

## What it does
- Chat with an open-source LLM (Qwen2.5-7B-Instruct)
- Gradio web UI
- Goal: add text-to-image and video generation in one unified chat

## Tech
Python, Transformers, Gradio, Google Colab

## Goal
Run these models locally on an NVIDIA GPU.

Built with help from Google Gemini.
